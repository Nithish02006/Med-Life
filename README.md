\# 🩺 Med Life — AI Virtual Nurse



Med Life is an AI-powered virtual nurse chatbot designed to provide users with a conversational interface for discussing common symptoms and accessing general health information.



\## ✨ Features



\- Interactive chatbot interface built using HTML, CSS, and JavaScript.

\- Flask backend for processing chat requests.

\- Ollama integration for AI-generated responses.

\- Image upload functionality with basic wound-care messaging.

\- Image and video search functionality for related health topics.

\- Friendly conversational interface.



\## 🛠️ Technologies Used



\- Python

\- Flask

\- Flask-CORS

\- Ollama

\- HTML

\- CSS

\- JavaScript

\- Pillow

\- DuckDuckGo Search

\## 🚀 Installation and Setup



\### 1. Clone the repository



```bash

git clone https://github.com/Nithish02006/Med-Life.git

cd Med-Life

```



\### 2. Install dependencies



```bash

pip install -r requirements.txt

```



\### 3. Start Ollama



Make sure Ollama is installed and running, and the model named `kind` is available.



\### 4. Run the application



```bash

python server1.py

```



\### 5. Open the interface



Open `UI.html` in your web browser while the Flask backend is running.
